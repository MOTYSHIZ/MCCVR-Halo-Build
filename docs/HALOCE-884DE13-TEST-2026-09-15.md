The source difference removes the HUD reader's live source-ticket requirement
in favor of the frozen in-flight eye receipt. The same candidate also changes
skin conversion, lens ownership and Original preparation guards. Assigning
causality requires reproducing the failing native contract rather than treating
any one concurrent source change as proof.
