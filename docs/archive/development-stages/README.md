# Historical development-stage files

This folder preserves the Stage 1–3 handoffs, patches, manifests, checksums,
static audits, and reverse-engineering notes that previously filled the
repository root. They remain available for provenance and older build
reproduction, but they do not describe the current release by themselves.

For the current project overview, start with the repository's main
[`README.md`](../../../README.md). Current accepted-build state lives in
[`docs/CURRENT-STATE.md`](../../CURRENT-STATE.md), and current build instructions
live in [`BUILDING.md`](../../../BUILDING.md).

Files in this folder retain their original names so old logs, package manifests,
and discussion references remain searchable.
